StreamBeam's first Android preview bundles the recent phone-to-PC improvements.

- Compact remote keyboard: tap Ctrl, Alt, Shift or Win, then a key. Alt+Tab is one tap; additional keys and shortcuts are in small menus.
- Touch cursor that fades when idle and hides when a controller is used.
- Controller focus/reconnect fixes and lighter Android streaming defaults.
- QR scanner release-build initialization fix and clearer pairing recovery.
- Startup storage initialization fix that preserves saved pairings.
- New flowing S logo and a quieter device screen after stopping a stream.

Download the ARM64 APK for modern Android phones/tablets (Android 8 or newer).
Install it over the existing preview to retain pairings. It uses the same
preview signing identity as the device builds.

This is a LAN-streaming preview. The Android APK is included; desktop packages
are not included in this release. Windows controller input requires the host's
VIIPER setup. CI checks compilation and automated regressions; it does not prove
camera scanning, GPU streaming performance or controller behavior on every
phone. The latest compact keyboard and QR camera flow still need full physical
phone verification after the Xiaomi wireless-debugging interruptions.
