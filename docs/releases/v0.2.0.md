StreamBeam's second Android preview collects the streaming, input and pairing
fixes made since 0.1.0.

- Android as a host: direct touch input and sharper capture, plus a fix for
  capture losing its reference frame during motion.
- Fewer false reconnect stall warnings, and the Android connection approval
  prompt works again.
- Saved devices refresh their status when you leave a stream.
- Opt-in network diagnostics for troubleshooting a connection.
- Desktop discovery falls back to the built-in Rust implementation where native
  Bonjour is unavailable.
- Under the hood: the same codebase now also builds an iOS viewer and an
  experimental browser viewer. Those are not part of this download.

Download the ARM64 APK for modern Android phones/tablets (Android 8 or newer).
Install it over 0.1.0 to keep your pairings. It uses the same preview signing
identity (version code 5).

This is a LAN-streaming preview. Only the Android APK is included; desktop,
iOS and browser builds are not part of this release. CI checks compilation and
automated regressions; it does not prove camera scanning, GPU streaming
performance or controller behavior on every phone.
